## 🛠️ Prompt Engineering Frameworks Quick-Reference

Want immediate value? Here is a cheat sheet of the four core frameworks utilized by this repository:

### 1. The RACE Framework (Best for General Tasks & Analysis)
- **R - Role:** Define who the AI should act as (e.g., *Senior Cybersecurity Analyst*).
- **A - Action:** State the exact verb and task (e.g., *Audit the attached firewall logs*).
- **C - Context:** Provide background and constraints (e.g., *We are a B2B SaaS startup facing brute-force attempts*).
- **E - Expectation:** Specify the format and success criteria (e.g., *Output a bulleted Markdown report prioritized by severity*).

### 2. The RTF Framework (Best for Copywriting & Content Production)
- **R - Role / Persona:** *Act as a viral LinkedIn ghostwriter.*
- **T - Task:** *Write a compelling post about the future of AI in healthcare.*
- **F - Format:** *Use short 1-2 sentence paragraphs, include 3 relevant hashtags, and end with a provocative question.*

### 3. Chain of Thought (CoT) (Best for Complex Math, Logic & Coding)
Add explicit instructions forcing the model to reason before finalizing its answer:
> *"Before writing the final SQL query, think step-by-step about the table joins required, identify any potential indexing bottlenecks, and explain your logic in scratchpad comment blocks."*

### 4. Prompt Chaining (Best for Enterprise & Multi-Step Systems)
Break monolithic tasks into sequential modular steps where the output of Prompt A becomes the input of Prompt B:
- **Step 1 (Extractor):** *Extract all dates and dollar amounts from this messy legal contract into JSON.*
- **Step 2 (Analyzer):** *Take the JSON from Step 1 and calculate the total quarterly liability.*
- **Step 3 (Synthesizer):** *Draft an executive summary email using the calculations from Step 2.*

## 💎 Pro-Tips: The 5 Golden Rules of Prompting

| Rule | ❌ Weak Prompt | ✅ Master Prompt (Prompt Engineer Pro) |
| :--- | :--- | :--- |
| **1. Define Explicit Roles** | *"Write a script to scrape web data."* | *"You are a Senior Principal Python Engineer specializing in high-throughput data pipelines. Write an asynchronous scraper using `aiohttp` and `BeautifulSoup`..."* |
| **2. Enforce Negative Constraints** | *"Summarize this financial report."* | *"Summarize this Q3 earnings report. Do NOT include conversational introductory text (e.g., 'Here is your summary'). Do NOT speculate on future stock prices."* |
| **3. Dictate Exact Output Formatting** | *"Give me a list of top customers."* | *"Return the top 10 customers as a valid JSON array of objects with keys: `customer_id`, `lifetime_value`, and `churn_risk_score`. No wrapping markdown."* |
| **4. Provide Few-Shot Examples** | *"Classify the sentiment of these tweets."* | *"Classify tweet sentiment as POSITIVE, NEGATIVE, or NEUTRAL. <br>Example 1: 'Love the new UI!' -> POSITIVE <br>Example 2: 'App crashes on launch' -> NEGATIVE <br>Now classify: 'The update is okay I guess.'"* |
| **5. Plan for Edge Cases** | *"Extract the email address from the bio."* | *"Extract the primary email address from the user bio string. If multiple emails exist, return the business email. If no valid email is found, return `null`."* |
